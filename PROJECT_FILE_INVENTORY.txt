DEMAND GENERATOR PROJECT FILE INVENTORY

The sequence follows the application workflow, then lists tests, project guidance,
documentation, assets, and the current packaged outputs.

Scope: maintained source files, documentation/assets, and the distribution files
currently present under artifacts\. Generated bin\ and obj\ build/intermediate
files are excluded because they are recreated by build and publish commands.
